    Worksheet 3.8. Laurent Series
    

    MTH 401

    Definition 48.

    A Laurent series centered at \(z_0\) represents a complex function \(f(z)\) as an infinite series of both positive and negative powers of \(z-z_0\text{.}\) It has the form
    \begin{equation*} f(z) = \ldots + c_{-2}(z-z_0)^{-2} + c_{-1}(z-z_0)^{-1} + c_0 + c_1(z-z_0)+c_2(z-z_0)^2+\ldots \end{equation*}
    with all negative powers collectively forming the principal part and the nonnegative powers collectively forming the Taylor series.
    🔗
    Coefficients in the principal part with \(n \lt 0\) can be found using
    \begin{equation*} c_n = \frac{1}{2\pi i}\oint\limits_C \frac{f(z)}{(z-z_0)^{-n+1}}~dz \end{equation*}
    while coefficients in the Taylor series part with \(n\ge 0\) are
    \begin{equation*} c_n = \frac{1}{2\pi i}\oint\limits_C \frac{f(z)}{(z-z_0)^{n+1}}~dz. \end{equation*}
    🔗
    🔗

    Remark 49.

    We rarely use those formulas to find the coefficients \(c_n\text{,}\) rather we usually use our Taylor series knowledge instead.
    🔗
    Recall again the following Taylor series:
    \begin{align*} e^u \amp = 1 + u + \frac{u^2}{2!} + \frac{u^3}{3!} + \ldots + \frac{u^n}{n!} + \ldots\\ \sin(u) \amp = u - \frac{u^3} {3!} + \frac{u^5}{5!} - \frac{u^7}{7!} + \ldots + (-1)^n\frac{u^{2n+1}}{(2n+1)!} + \ldots\\ \cos(u) \amp = 1 - \frac{u^2}{2!} + \frac{u^4}{4!} - \frac{u^6}{6!} + \ldots + (-1)^n\frac{u^{2n}}{(2n)!} + \ldots \end{align*}
    🔗
    🔗

    Definition 50.

    The coefficient \(c_{-1}\) in the Laurent series of a complex function \(f(z)\) is called the residue of \(f(z)\) at z-z_0, denoted
    \begin{equation*} \text{Res}_{z_0} f(z). \end{equation*}
    If \(f(z)\) has only one singularity at \(z_0\) and \(z_0\) is inside \(C\text{,}\) then
    \begin{equation*} \oint\limits_C f(z)~dz = 2\pi i \ \text{Res}_{z_0}f(z). \end{equation*}
    🔗
    🔗

    Definition 51.

    There are three types of singularities that can be classified by their Laurent series given by
    \begin{equation*} f(z) = \ldots + \frac{c_{-2}}{(z-z_0)^2} + \frac{c_{-1}}{z-z_0} + c_0 + c_1 (z-z_0) + \ldots. \end{equation*}
    The three types are classified by how many coefficients \(c_k\) corresponding to negative powers ( \(k\lt 0\) ) are nonzero.
    🔗
    1. Removable singularity: \(c_k = 0\) if \(k<0\text{.}\)
      🔗
      🔗
    2. Pole: There are only finitely many nonzero \(c_k\) with \(k\) negative.
      🔗
      🔗
    3. Essential singularity: There are infinitely many nonzero \(c_k\) with \(k\) negative.
      🔗
      🔗
    🔗
    🔗

    Definition 52.

    The order of a pole (see definition above) is the smallest positive integer \(M\) where \(c_k = 0\) if \(k < -M\text{.}\)
    🔗
    🔗

    Identify.

    The first three examples illustrate each of these types. Which is which?
    🔗
    🔗

    (b)

    What is the order of the pole from the first three examples?
