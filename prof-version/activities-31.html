    Worksheet 3.2. Complex functions
    

    MTH 401
    We want to spend some time exploring complex functions \(f(z)\) where \(z = x+iy\text{.}\)
    🔗

    1.

    Consider the function \(f(z) = e^z = e^xe^{iy}\text{.}\)
    🔗

    (a)

    Plot the following points, and describe what happens to \(f(1+iy)\) as \(y\) varies. \(f(z)\) when
    🔗
    • \(\displaystyle \ds z=1+i\frac{\pi}{2}\)
      🔗
      🔗
    • \(\displaystyle z=1+i\pi\)
      🔗
      🔗
    • \(\displaystyle z=1+i2\pi\)
      🔗
      🔗
    🔗

    (b)

    Plot the following points, and describe what happens to \(\ds f(x+i\frac{\pi}{4})\) as \(y\) varies.
    🔗
    • \(\displaystyle \ds z=-1+i\frac{\pi}{4}\)
      🔗
      🔗
    • \(\displaystyle \ds z= 0+i\frac{\pi}4\)
      🔗
      🔗
    • \(\displaystyle \ds z=1+i\frac{\pi}4\)
      🔗
      🔗
    • \(\displaystyle \ds z=2+i\frac{\pi}4\)
      🔗
      🔗
    🔗

    (c)

    Since \(f(z) = e^xe^{iy}\text{,}\) what is \(|f(z)|\text{?}\) What is \(\arg(f(z))\text{?}\)
    🔗
    🔗

    (d)

    If we fix the value of \(y=y_0\text{,}\) what is the image of a horizontal line \(f(x + iy_0)\) as \(x\) varies?
    🔗
    🔗

    (e)

    If we fix the value of \(x=x_0\text{,}\) what is the image of a vertical line \(f(x_0 + iy)\) as \(y\) varies?
    🔗
    🔗

    (f)

    Given a square grid in the \(z\)-plane, sketch its image in the \(w=f(z)\) plane.
    🔗
    🔗
    🔗

    2.

    Remember that the natural logarithm is defined to be the inverse of the exponential function; that is, \(\ln(z) = w\) if \(e^w = z\text{.}\)
    🔗

    (a)

    Find the points \(w\) that satisfy \(e^w = -1\text{.}\) How many are there and how are they related to one another?
    🔗
    🔗

    (b)

    Defining \(\ln(x+iy) = u + iv\) means that \(e^{u+iv}=e^ue^{iv}=x+iy\text{.}\) Write \(u\) and \(v\) as functions of \(x\) and \(y\text{.}\) Are both of these functions continuously defined?
    🔗
    🔗
    🔗

    3.

    Suppose that \(\ds m = 2e^{i\frac{\pi}4}\) and suppose that \(z\) is complex number.
    🔗

    (a)

    How does \(|mz|\) compare to \(|z|\text{?}\)
    🔗
    🔗

    (b)

    How does \(\arg(mz)\) compare to \(\arg(z)\text{?}\)
    🔗
    🔗

    (c)

    What is the geometric effect of multiplying \(z\) by \(m\) to obtain \(mz\text{?}\)
    🔗
    🔗

    (d)

    Suppose that \(f(z) = mz\text{.}\) Given a square grid in the \(z\)-plane, sketch its image in the \(w=f(z)\) plane.
    🔗
    🔗
    🔗

    4.

    Suppose that \(f(z) = z^2\text{.}\) Let’s write \(z=re^{i\theta}\) in polar form.
    🔗

    (a)

    What is \(f(re^{i\theta})\text{?}\)
    🔗
    🔗

    (b)

    If we hold \(r=r_0\) fixed, what is the image of the circle \(f(r_0e^{i\theta})\) as \(\theta\) varies?
    🔗
    🔗

    (c)

    If we hold \(\theta=\theta_0\) fixed, what is the image of the ray \(f(re^{i\theta})\text{?}\)
    🔗
    🔗

    (d)

    Instead of a square, rectangular grid, consider a ``polar grid’’ in the \(z\)-plane consisting of concentric circles centered at the origin and radial lines emerging from the origin. Sketch such a grid and then sketch the image of this grid.
    🔗
    🔗
    🔗

    5.

    Remember that \(\ds\cos(\theta) = \frac{e^{i\theta} + e^{-i\theta}}{2}\text{.}\) Suppose we define \(\ds\cos(z) = \frac{e^{iz} + e^{-iz}}{2}\text{.}\)
    🔗

    (a)

    Find functions \(u(x,y)\) and \(v(x,y)\) such that \(\cos(x+iy) = u(x,y) + iv(x,y)\text{.}\)
    🔗
    🔗

    (b)

    Find the points \(z\) for which \(\cos(z) = 2\text{.}\)
    🔗
    🔗
